# Thin input (not a ready story)

Warehouse problem: after inspection, the next shift can see the delivery but
cannot see that it was sealed / inspection passed. People send “ok to put
away” in chat.

Wanted: an operator can mark that a delivery is sealed (inspection done) so
the warehouse sees that fact on the delivery itself — not a side channel.

This is not “waiting to put away” and not “damaged”. It is a separate
warehouse fact. Optional note (length limit not decided). No money amount —
finance does not look at this.

Not thought through yet: new mark vs reuse existing warehouse flags/notes,
whether the submitting user must be identified, list of all sealed
deliveries vs lookup of one, max note length.

No service names. No AC. No tracker.
